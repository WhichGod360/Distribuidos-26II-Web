Bibliotecas del servicio ASMX WebServices_Biblioteca.

El proyecto webServices referencia las cuatro capas compiladas y las dependencias SQL y de
seguridad de esta carpeta. Para reconstruir capaConexion, capaDatos, capaDAO y capaNegocio,
ejecuta .\Build-Backend.ps1 desde la carpeta WebServices_Biblioteca. El script actualiza
las cuatro DLL y SHA256SUMS.txt.

El código fuente de las capas se comparte desde Distribuidos-26II-escritorio.
LICENCIAS contiene metadatos y avisos correspondientes a las dependencias.
